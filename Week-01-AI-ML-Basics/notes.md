Week 1 – Introduction to AI and ML

Objective:

The objective of Week 1 is to understand the basic concepts of Artificial Intelligence (AI) and Machine Learning (ML), their types, applications, and commonly used terminology.

1. What is Artificial Intelligence?

Artificial Intelligence is a field of computer science where we try to make machines perform tasks that normally require human intelligence.
Some examples are understanding language, recognizing images, making decisions, solving problems and learning from information.

2. What is Machine Learning?

Machine Learning is a part of Artificial Intelligence. In machine learning, the computer learns patterns from data and uses the learned patterns to make predictions or decisions.

For example, if we provide a model with information about houses such as area, location and number of rooms along with their prices, the model can learn from this data and predict the price of a new house.

3. Difference between AI, ML and Deep Learning:

AI is the broader concept of making machines perform intelligent tasks.

Machine Learning is a part of AI where machines learn from data.

Deep Learning is a part of Machine Learning. It mainly uses neural networks with multiple layers to learn complex patterns from large amounts of data.

So the relationship can be understood as:

AI → Machine Learning → Deep Learning


4. Types of Machine Learning:

* Supervised Learning

In supervised learning, the model is trained using labelled data. This means that the input data and the expected output are already known.

Examples- regression and classification.

For example, predicting the price of a house based on its features is a regression problem.

* Unsupervised Learning

In unsupervised learning, the data does not have predefined output labels. The model tries to find patterns or groups within the data.

Clustering is a common example. For instance, customers can be grouped based on their purchasing behaviour.

* Reinforcement Learning

In reinforcement learning, an agent learns by interacting with an environment. It receives rewards for good actions and penalties for unwanted actions.

One example is training an AI system to play a game.


4. Regression:

Regression is used when the output we want to predict is a continuous numerical value.

For example, predicting house prices, temperature or sales.


5. Classification:

Classification is used when the output belongs to a particular category.

For example, an email can be classified as spam or not spam.


6. What is Generative AI?

Generative AI is a type of AI that can generate new content based on patterns learned from existing data.

It can be used to generate text, images, audio, video and code.

Examples include AI chat assistants, image generation tools and AI coding assistants.


7. Some important terms:

* Dataset – A collection of data used for analysis or machine learning.

* Feature – An input variable that is given to a machine learning model.

* Label – The expected output associated with an input in supervised learning.

* Model – A system that learns patterns from the given data.

* Training – The process in which the model learns from data.

* Testing – Checking how well a trained model works on new or unseen data.

* Prediction – The output produced by a trained model.

* Accuracy – A measure of how many predictions made by a classification model are correct.


8. Applications of AI and ML:

AI and ML are being used in many areas such as healthcare, finance, cybersecurity, recommendation systems, computer vision, natural language processing, fraud detection and autonomous systems.
